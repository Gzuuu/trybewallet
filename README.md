# TrybeWallet 💳

**TrybeWallet** é uma carteira virtual para gerenciamento de despesas, com funcionalidades que incluem conversão de moeda (como dólar para real) usando uma API externa. O aplicativo permite que o usuário adicione, edite e exclua despesas, acompanhe o total gasto e converta os valores para diferentes moedas.

## 🛠️ Funcionalidades

- **Gerenciamento de despesas**: Adicionar, editar e excluir despesas.  
- **Verificação de valor total**: Visualizar o total gasto com todas as despesas.  
- **Conversão de moedas**: Converter valores para outras moedas (como de dólar para real).  
- **Login do usuário**: O usuário pode realizar login com e-mail e senha (verificação simples).  
- **LocalStorage**: Armazenamento dos dados do usuário para permitir o login persistente.  

## 🚀 Tecnologias Utilizadas

- **JavaScript**  
- **React**  
- **APIs externas** (Exemplo: API de conversão de moeda)  
- **LocalStorage** para gerenciamento de login  

## 🧑‍💻 Instalação

1. Clone o repositório:  
   git clone https://github.com/Gzuuu/trybewallet.git  

2. Navegue até a pasta do projeto:  
   cd trybewallet-project  

3. Instale as dependências:  
   npm install  

4. Execute o projeto:  
   npm start  

## 📂 Observações

- Todos os arquivos modificados estão localizados dentro da pasta `src/`.  
- A parte de CSS não foi um foco neste projeto e, portanto, não foi desenvolvido.
